## 📋 Deskripsi
Bot WhatsApp multi-fitur berbasis Baileys

## 📦 Requirement
- Node.js v18+
- npm
- WhatsApp

## 🚀 Instalasi

1. Clone repository
git clone https://github.com/RuhtWalker/adi-ai-md.git
cd adi-ai-md

2. Install dependencies
npm install

3. Jalankan bot
node index.js

## ⚙️ Konfigurasi
Edit file config.js sesuai kebutuhan
